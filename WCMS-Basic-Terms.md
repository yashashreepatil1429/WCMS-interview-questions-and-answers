# WCMS Basic Terms

1. What is Web Content Development?

Web Content Development is the process of planning, creating, and publishing useful information on a website.

2. What is a Website?

A website is a collection of related web pages available on the internet under one domain name.

3. What is a Web Page?

A Web Page is a single document on the internet that can contain text, images, videos, and links.

4. What is SEO?

SEO stands for Search Engine Optimization. It helps improve the visibility and ranking of a website in search engine results.

5. What is a Domain Name?

A Domain Name is the unique address of a website on the internet, such as google.com.

6. What is Web Hosting?

Web Hosting is a service that stores website files on a server and makes them available on the internet.

7. What is Content Publishing?

Content Publishing is the process of making website content available to users on the internet.

8. What is Version Control?

Version Control is a system that records changes made to website content and allows users to track earlier versions.

9. What is User Management?

User Management is the process of creating user accounts and assigning roles and permissions.

10. What is a Media Library?

A Media Library is a storage area used to organize images, videos, audio files, and documents.

11. What is Multimedia?

Multimedia is the combination of different forms of media such as text, images, audio, video and animation.

12. What is Multimedia Content?

Multimedia Content is information presented using text, images, sound, videos and animations.

13. What is Presentation Software?

Presentation Software is an application used to create and display slides containing text, images, charts and videos.

14. What is Screen Casting?

Screen Casting is the process of recording computer or mobile screen activities in video format.

15. What is Screen Recording?

Screen Recording is the process of capturing activities taking place on a computer or mobile screen.

16. What is Shared Hosting?

Shared Hosting is a type of hosting in which multiple websites share the resources of one server.

17. What is Dedicated Hosting?

Dedicated Hosting provides an entire server to a single website or organization.

18. What is Cloud Hosting?

Cloud Hosting uses multiple connected servers to store and manage website data.

19. What is VPS Hosting?

VPS stands for Virtual Private Server. It provides a virtual server with dedicated resources within a physical server.

20. What is Audio Content?

Audio Content is digital information presented in sound format, such as music, podcasts and voice recordings.
