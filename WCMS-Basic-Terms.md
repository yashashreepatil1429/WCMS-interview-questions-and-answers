# WCMS Basic Terms

1. What is Web Content Development?

Web Content Development is the process of planning, creating, and publishing useful information on a website.

2. What is a Website?

A website is a collection of related web pages available on the internet under one domain name.

3. What is a Web Page?

A Web Page is a single document on the internet that can contain text, images, videos, and links.

4. What is SEO?

SEO stands for Search Engine Optimization. It helps improve the visibility and ranking of a website in search engine results.

5. What is a Domain Name?

A Domain Name is the unique address of a website on the internet, such as google.com.

6. What is Web Hosting?

Web Hosting is a service that stores website files on a server and makes them available on the internet.

7. What is Content Publishing?

Content Publishing is the process of making website content available to users on the internet.

8. What is Version Control?

Version Control is a system that records changes made to website content and allows users to track earlier versions.

9. What is User Management?

User Management is the process of creating user accounts and assigning roles and permissions.

10. What is a Media Library?

A Media Library is a storage area used to organize images, videos, audio files, and documents.
